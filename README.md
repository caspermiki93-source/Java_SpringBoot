# Java + Spring Boot

Repositorio de aprendizaje y desarrollo con **Java y Spring Boot**.

El proyecto comienza siguiendo un tutorial práctico de Spring Boot y, progresivamente, irá evolucionando hacia un proyecto propio, incorporando los conocimientos y tecnologías aprendidos durante el desarrollo.

EL canal de youtube es Informaticonfig: https://www.youtube.com/watch?v=5M39KMhVOWA&list=PL2Z95CSZ1N4EWw14HZ0NFD3woFcn6uiCm&index=2

## 📚 Contenido

Actualmente, el repositorio contiene los ejercicios y ejemplos desarrollados durante el tutorial:

- Spring Boot
- Spring MVC
- Controladores REST
- Servicios
- Repositorios
- DTOs
- JPA / Hibernate
- MySQL
- Spring Security
- Autenticación y autorización
- Thymeleaf
- HTML y CSS
- Consumo de APIs REST

## 🛠️ Tecnologías

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- MySQL
- Maven
- Thymeleaf
- HTML5
- CSS3
- Git / GitHub
